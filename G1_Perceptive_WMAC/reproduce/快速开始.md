# G1 视觉越野行走训练

这个项目复现了 `Unitree-G1-AMP-Perceptive-Hiking` v3。默认策略使用四专家 MoE、八帧深度图和 Hiking AMP 动作数据。代码、机器人模型、动作源、依赖锁和校验清单随仓库提供。

## 安装与短测

下载或克隆项目到 Linux x86_64 机器上一个路径不含空格的目录。在有 NVIDIA 驱动的机器上，进入包含 `src/` 和 `reproduce/` 的项目目录后执行：

```bash
bash reproduce/install.sh
bash reproduce/smoke-local.sh
```

安装器会下载锁定的 Miniforge 和 Python 依赖，准备专家数据并运行 CPU 回归。短测从零开始，在 16 个并行环境中推进 200 个控制步。本项目曾在 RTX 4080 16 GB 上完成该短测，最终检查点为 `model_24.pt`。检查点名使用 learner 更新次数。训练日志保存在 `logs/wmac_perceptive/`。

## 正式训练

手册中的正式配置面向 80 GB 级 GPU。在项目目录执行：

```bash
source reproduce/activate.sh
python scripts/train_wmac_perceptive.py \
  --execution-profile supermimic --num-envs 4096 --seed 42 \
  --iterations 1000000 --run-name hiking_v3_from_zero
```

完整训练参数、断点恢复和物理仿真评估见[复现手册第 13 章](FRAMEWORK_REPRODUCTION_zh.md)。MuJoCo-Warp 3.8.1 原版在短测中出现过高度场碰撞警告，手册第 12.6 节说明了可选修复。第三方代码和数据的来源及各自条款见[第三方声明](../THIRD_PARTY_NOTICES.md)。
