# Upstream reference tests

This directory contains the 15 Python source files used by the CPU regression tests and the corresponding upstream licenses. The [source manifest](../local-checks/upstream-source-provenance.json) lists pinned commits and SHA-256 checksums for all five projects. These upstream modules are used only by the reference tests.

Activate the environment at the project root to check SuperMimic GenCoord and its collection clock, and the InstinctMJ visual networks and gradients.

```bash
source reproduce/activate.sh
export PYTHONPATH="$PWD:$PWD/tests"
export SUPERMIMIC_REFERENCE_CHECKOUT="$PWD/reproduce/references/supermimic"
export INSTINCTMJ_REFERENCE_CHECKOUT="$PWD/reproduce/references/InstinctMJ"
CUDA_VISIBLE_DEVICES="" python -m unittest -v \
  test_perceptive_reference_schedule test_reference_visual_gradients \
  test_wmac_gencoord test_perceptive_latent_models
```

Three additional tests use paths hard-coded in the test suite. In the same activated shell, the following command creates temporary links at those paths if they are available, checks the 26 reward terms, foot volume-point velocities, and AMP sample ordering, and removes the links it created.

```bash
CUDA_VISIBLE_DEVICES="" python - <<'PY'
from contextlib import ExitStack
from pathlib import Path
import subprocess
import sys

sources = Path("reproduce/references").resolve()
locations = {
    "/tmp/hiking_locomotion_source": sources / "InstinctLab",
    "/tmp/hiking-isaaclab-camera-reference": sources / "IsaacLab/source/isaaclab/isaaclab/envs/mdp",
    "/tmp/instinct-rl-hiking-reference": sources / "instinct_rl",
}

def remove_own_link(link, target):
    if link.is_symlink() and link.readlink() == target:
        link.unlink()

with ExitStack() as cleanup:
    for name, target in locations.items():
        link = Path(name)
        if link.is_symlink() and link.resolve() == target:
            continue
        link.symlink_to(target, target_is_directory=True)
        cleanup.callback(remove_own_link, link, target)
    subprocess.run([
        sys.executable, "-m", "unittest", "-v",
        "test_hiking_full_rewards.HikingFullRewardsTest.test_all_26_terms_match_executed_pinned_original",
        "test_hiking_full_rewards.HikingFullRewardsTest.test_volume_points_velocity_matches_original_sensor_with_com_velocity",
        "test_hiking_amp_budget.HikingAmpBudgetTest.test_minibatch_order_matches_actual_hiking_storage_and_reuses_one_shuffle",
    ], check=True)
PY
```

Two other Hiking AMP reference tests require a script generated by the original author at `/tmp/hiking_amp_reference_oracle.py`. It was not included with the handbook, so these tests were skipped in the local CPU runs.
